Offensive line analysis

Public play-by-play only. Sack rate and QB-hit rate are per dropback. Adjusted line yards: run yards credited to the line (losses ×1.2, 0–4 yds full, 5–10 half, 11+ none). Stuff rate = runs for 0 or fewer yards. Rush EPA by direction uses the charted run location/gap. Pressures aren't in the public data, so they're not shown. Pass-block and run-block chips are Sports Labs ratings (0–100 percentile), not grades; no individual lineman ratings.
