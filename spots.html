Coverage & how to read these views

Manual preview built from existing Hub snapshots; no new feeds or scheduled jobs. Current-game offers fail closed after90minutes or kickoff, on source changes, and on season/game mismatches. These are not live prices or new picks.

Line Checks compare native reference lines; bookmaker provenance is not supplied. Histories use only explicitly present2026 native stat fields, not zero-filled summary logs: over means strictly greater; equality is a push. Missing stats are excluded, not zero-filled. Win rate excludes pushes and is not a forecast. TD estimates and Highlighted flags are the existing Hub values, unchanged; quoted implied odds are raw, not de-vigged.

Rising Roles compares the latest three observed games with the preceding three on the same team. It is descriptive, not injury redistribution. Matchups show only supplied game lines/totals. Soft Spots uses recorded positional allowance averages, not a matchup projection. RB positional yardage split is unverified, so no rushing/receiving split is inferred.

Verified red-zone splits, touch coordinates, causal injury effects, timestamped line movement, calibrated forecasts and unsupported measurements are not supplied.
